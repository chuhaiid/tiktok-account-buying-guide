## 邮箱在线收码与常见报错

**收码的顺序。** 收码网址显示的是 TikTok 发到这个邮箱的邮件,你没在 TikTok 点发送,自然什么都查不到。正确顺序是:TikTok 页面点发送 → 切到收码网址输入邮箱 → 间隔 1 到 2 分钟刷新一次。邮箱地址要和卡密完全一致,多一个空格、少一个字母都查不到,建议直接从卡密里复制。

## 改邮箱、改密码:什么时候动、按什么顺序

**为什么要换绑。** 卡密里的邮箱靠的是商家接入的收码服务。想让号真正握在自己手里,长期看验证码要收在你自己的邮箱里。美区号的收码接口约 30 天有效,对它来说换绑不是可选项,是必做项。

**两个「密码」别搞混。** 商品页说的「不要修改邮箱密码」,指的是卡密里那个邮箱自身的密码,你本来也拿不到;TikTok 的登录密码是另一回事,稳定之后可以改成自己的。换绑完成后,把新邮箱、新密码、绑定的手机号三样记在安全的地方。
